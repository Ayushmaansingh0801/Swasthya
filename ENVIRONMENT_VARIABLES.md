# ENVIRONMENT_VARIABLES.md

See `.env.example` and `server/.env.example` for full list. Key variables:

## Server
- PORT, NODE_ENV
- MONGODB_URI
- JWT_SECRET, JWT_REFRESH_SECRET (>=32 chars)
- FRONTEND_ORIGIN
- AI_PROVIDER (mock|gemini|openai), AI_API_KEY
- MAP_API_KEY, GOOGLE_PLACES_API_KEY
- EMAIL_PROVIDER, SMTP_HOST/PORT/USER/PASS
- STORAGE_DIR
- SEED_ON_START, SEED_RESET
- RAZORPAY_KEY_ID, RAZORPAY_KEY_SECRET
- BOOTSTRAP_ADMIN_EMAIL, BOOTSTRAP_ADMIN_PASSWORD
- ALLOW_ROLE_SIGNUP (dev only)
- REDIS_URL (optional)

## Client
- VITE_GOOGLE_MAPS_API_KEY (optional)
- VITE_API_BASE (optional)
